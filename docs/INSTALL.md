# Instalar SA Delirium en Steam

Usa el asistente de [la entrega de desarrollo](https://github.com/AdriiSuizo/sa-delirium/releases/tag/v0.2.0-dev-import.1).
Abre `SA-Delirium-Setup.exe`, revisa las carpetas y pulsa **Comprobar → Instalar**.
Si alguna no se detecta, pulsa **Examinar**. Después abre el juego con **Jugar** en Steam.

El instalador incluye nuestras físicas y adaptador y necesita una copia local
compatible de desarrollo para importar el juego y los otros mods. Se requieren
unos 20,7 GiB más 1 GiB de margen. No descarga el modpack completo desde cero.

Consulta [la guía del asistente](../installer/LEEME.txt) para requisitos,
partidas, restauración y el contenido exacto. Los archivos originales de Steam
se conservan; su ejecutable se respalda antes de instalar el lanzador propio.

La instalación por extracción directa correspondía a
[los candidatos históricos del port nativo R2](INSTALL-NATIVE-R2.md).
