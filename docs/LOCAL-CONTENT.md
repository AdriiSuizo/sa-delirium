# Local personal content

This archive contains user-supplied visual mods imported locally. Their inclusion
does not grant redistribution rights. Do not upload this archive to GitHub,
Releases, mirrors or public modpack sites. The generated `provenance.json`
identifies each source and priority. Original archives and downloads are intact.

This is a scoped integration candidate, not the complete requested visual pack.
No RoSA or Proper Player assets are included: their author explicitly prohibits
modpack inclusion. The code supports owner-side imports independently of the
publicly distributable payload. Never mark local data as redistributable merely
to bypass the release builder's guard.

On first startup the mod composes a separate IMG from your own SA archive and the
replacement blobs. It keeps the original unchanged. Generated archives and
`DeliriumSA-local-v3` contain local game data and must not be redistributed.

Remove `SAStandalone-assets`, `SAStandalone-asset-cache` and
`SAStandalone-assets-active.tsv` to remove this optional visual layer. Core
uninstallation is described in `SAStandalone-LEEME.md`.
